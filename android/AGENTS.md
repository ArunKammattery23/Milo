# Milo project instructions

Use https://github.com/ArunKammattery23/Milo.git as the canonical repository for all Milo work. Work from its checkout and push requested changes there. Preserve the existing Milo emoji/artwork and expressions unless the user asks to change them. Keep conversation screens simple; place advanced options in contextual menus. Never commit API keys, local.properties, signing material, build outputs or private user data. Publish the existing Milo Site through its Sites workflow without changing its audience.
